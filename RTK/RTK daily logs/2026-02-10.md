
## Ntrip Test Log

RTK module was powered on and connected to ntrip server ip via wifi.

RTCM 3 messages received at a considerable speed at the beginning and module entered float mode right away (<10s).

Received correction rate increased in a while (approx 1 min). 

Module entered fix mode after approx 18 to 30 mins , for several iterations.

### Test 1:

After achieving RTK fix , tested the module for dynamic stability  

Lifted antenna and displaced - module went into float mode right away 

### Test 2:
After achieving RTK fix 

Dragged the antenna along with the pole gently  -  fix remained unchanged and position estimate was reliable without any fluctuations.

When dragged the antenna further inside the roof , module entered float mode immediately.

Standard position data estimated in ntrip mode - lat = 13.02252783  lon = 80.20751600  Alt = -69.8 m  Alt (msl) = 17.2 m 
### Test 3:

Antenna is typically placed on a elevated surface from ground while testing

Shifted the antenna to ground - Fix stayed and Altitude estimate was precise

Shifted the antenna back to further high than usual - Fix state remained unchanged and Altitude estimate was close to accurate
