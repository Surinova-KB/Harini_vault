
Node - A Code / control block which executes a particular function.

Topic - A pipe line like data bus , carrying a particular type of data.

Publisher - A Standalone code block or sometimes part of a node, communicated with a topic and delivers data from node to the topic it's publishing to.

Subscriber - A Standalone code block or sometimes part of a node, communicated with a topic and retrieves data from topic to and deliver it to the node that's subscribing to that topic. 

Parameter - A  Data that's stored in server and can be called in at places necessary.

Message - Type of the data a topic is carrying. 

ROS Master - Master node which is controlling all the process and function , data transfer in the                           ROS system.

Service - A request send by one node to other , other node responds only when the service                             request is  complete.

Action - An action to complete a goal set by one node to other , other nodes feeds real time feed                 back until goal is achieved and result once the goal is achieved.
