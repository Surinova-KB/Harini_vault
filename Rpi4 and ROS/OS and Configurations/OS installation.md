
==Reason to choose pi4 :== ROS2 humble is compatible to Ubuntu jammy jellyfish 22.04.05 lts. And pi 4 is the latest compatible PC to run humble.

Installing OS into Rpi4:

 1.Micro SD of capacity 128 gb is connected to a PC with Pi imager software.
 2.Pick the Pi device that needs to be flashed with OS
 

  ![[Pasted image 20251227105733.png]]

  3.From the options in the imager choose os and navigate to other general purpose os and ubuntu.
  4.Choose the ubuntu 22.04.5  LTS (64-bit ) server os version.

![[Pasted image 20251227110148.png]]

5.Next select the Micro SD from storage and and write.
6.Wait till it writes and verify the os.
7.Now place the Micro SD in RPi 4 and rest of the set up is taken care by Rpi, makesure to plug in ethernet or enable wifi.
